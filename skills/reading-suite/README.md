# Reading Suite v2.0

完整的知识管理工作流：精读笔记 + 原子化卡片提取 + 全局复盘优化

---

## 设计理念

基于卢曼卡片盒方法论和知识生产三阶段模型：

1. **输入阶段（阅读）** — 只读，不做任何笔记，和作者同频
2. **提取阶段（拆卡片）** — 跳出作者框架，建立你自己的索引
3. **维护阶段（复盘）** — 站在全局高度，找重复、补盲区、去冗余

## 核心特性

### 📖 阅读模式
- **四角色系统**：思考伙伴 / 魔鬼代言人 / 苏格拉底辅导员 / 同行评审
- **硬约束设计**：角色边界不可绕过，不通过校验就重写
- **四层锚点对话**：时间 / 内容 / 主题 / 回流，精确关联到笔记行号
- **断点续读**：所有状态落盘，下次回来继续

### 🃏 卡片模式
- **交互式拆分**：AI出草案，你可以调整、合并、补充
- **语义提取**：自动识别适合拆成卡片的内容
- **双向链接**：自动维护卡片和原文的关联

### 🔍 复盘模式
- **全局扫描**：自动发现重复定义、结论冲突、知识盲区、内容冗余
- **交互式处理**：逐个问题确认、合并、标记忽略
- **复盘报告**：自动生成完整的复盘记录

## 技术设计

### 架构
```
main.py (统一入口)
    ↓
intent_analyzer.py (意图识别)
    ↓
├── read.py (阅读模式)
├── cards.py (卡片模式)
└── review.py (复盘模式)
    ↓
shared/ (基础设施层)
├── state_manager.py (状态管理，降级处理)
├── dialogue_writer.py (对话写入，索引维护)
├── file_lock.py (并发安全，死锁清理)
├── logger.py (统一日志)
├── role_validator.py (角色硬约束)
└── file_utils.py (路径处理，配置加载)
```

### 健壮性设计
- 所有状态落盘，内存不留任何状态
- 状态文件损坏自动降级，不会崩溃
- 所有文件操作带锁，并发安全
- 死锁自动清理机制（TTL 60秒）
- 输入长度限制（10万字）
- 完整的操作审计日志

## 使用方式

零参数自然语言驱动，不需要记任何命令：

| 你说什么 | 系统理解为 |
|:---------|:-----------|
| "帮我读一下这篇文章" | 标准精读模式 |
| "挑挑毛病，唱个反调" | 切换到魔鬼代言人 |
| "引导我想想" | 切换到苏格拉底模式 |
| "读完了，拆成卡片" | 卡片拆分模式 |
| "复盘一下最近一周" | 全局复盘模式 |
| "先到这，明天继续" | 保存状态，断点续读 |
