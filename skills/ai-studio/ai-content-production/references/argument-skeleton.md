# 论证骨架模板

> 写之前先搭骨架，骨架顺了再动笔。
> 每篇文章的骨架 = 一条推理链，读者是被一步步推到结论的，不是被喂了一堆素材。
> 素材形状决定骨架形状，写之前先选骨架，不要永远用五段式。

## 6 种论证骨架

| 骨架名 | 结构 | 适用素材形状 | 标志性特征 |
|--------|------|-------------|-----------|
| **标准因果式** | 现象→原因→反方→判断→影响 | 单个事件/趋势，有因有果 | 最通用的五段式 |
| **对比式** | A全貌→B全貌→关键差异→各自优劣→我的判断 | 两个东西的比较（产品/路线/模式） | 有明确的对比双方 |
| **层层剥笋式** | 表面现象→直接原因→深层原因→根本矛盾→出路 | 有深层矛盾的顽疾/反复出现的问题 | 可以连续问三层"为什么" |
| **多方视角式** | 事件→A方立场→B方立场→C方立场→我的判断 | 有争议的事件，各方立场差异大 | 至少三方有明显不同的利益和观点 |
| **叙事体** | 背景→问题→关键转折→结果→启示 | 一个公司/一个人/一个产品的故事 | 有时间线、有戏剧性转折 |
| **多源融合式** | 事件A→事件B→事件C→合在一起看→核心判断 | 多个独立事件指向同一个趋势 | 至少3个独立来源的独立事件 |

> 可以嵌套使用：大骨架套小骨架。比如多源融合式的外层骨架里，每个事件内部用因果式展开。

## 写之前必须填完的五个框（通用）

无论选哪种骨架，都先填这五个框：

```
1. 核心论点（一句话说清你要说服读者相信什么）
   → 

2. 主要论据（2-3 个独立证据支撑论点）
   → 证据1：
   → 证据2：
   → 证据3：

3. 反方观点（读者可能反对什么，真实的反方怎么说的）
   → 

4. 让步或反驳（承认反方的合理之处，或者反驳回去）
   → 

5. 最终结论（读完文章读者应该带走什么判断）
   → 
```

## 骨架常见错误

| 错误 | 表现 | 修正 |
|------|------|------|
| 分类筐 | 小标题是"为什么值得关注"，下面列了3条并列原因但没推进 | 小标题应该是论点，不是分类标签。改为"效率方向的拐点到了" |
| 没有反方 | 全是正面论证，读者觉得"太片面" | 必须有专门的反方章节，至少3个真实局限 |
| 跳过收束 | 摆完事实+反方就结束了，没有给出自己的判断 | 必须有第四节收束，把前三节的矛盾统一起来 |
| 收束太软 | "我们要辩证地看" | 收束必须有明确的判断，敢站边 |
| 五段不齐 | 少了某一段，推理链断裂 | 写之前检查五个框是否都填满了 |
| 骨架选错 | 素材是三个独立事件却用了因果式，素材是单个事件却用了多源融合式 | 素材形状决定骨架形状，不匹配读者会感觉散或别扭 |
