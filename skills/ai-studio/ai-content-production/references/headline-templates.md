# 头条标题公式与真实性约束

> 源自 ../../shared/RULES.md「断言与证据匹配」。所有头条标题必须遵守。

## 标题三级匹配制

| 级别 | 适用条件 | 标题特征 | 反例 |
|------|----------|----------|------|
| L1 事实级 | 只有事件/数据，无充分论证的趋势判断 | 陈述事实+限定范围 | 任何"颠覆""革命""变天" |
| L2 趋势级 | ≥3个独立证据指向同一方向，有合理因果链 | "X正在发生，值得关注" | "改写规则""彻底改变" |
| L3 判断级 | 趋势已被市场验证（产品/数据/财报支撑） | 明确判断+具体场景 | "下半场""新时代""终结" |

**判断方法**：写完标题问自己——"内容里的证据撑得住这个标题吗？"撑不住就降级。

## 可用公式（带真实性约束）

| 公式 | 结构 | 约束 |
|------|------|------|
| 数字清单型 | "N个XX，YY" | 数字要真实 |
| 反常识型 | "别再XX了，真正的XX是XX" | 反常识点必须有数据支撑，不能自己造反差 |
| 亲测型 | "我XX了一周/一个月，真实感受" | 必须是亲测 |
| 对比型 | "XX vs YY，差距比想象的大" | 差距必须有具体数字 |
| 警示型 | "XX正在发生，再不XX就晚了" | 禁止制造焦虑，必须有真实风险 |
| 效率型 | "学会这招，XX效率翻X倍" | 效果必须有验证 |

## 套话黑名单（直接替换）

| 禁用 | 替换为 |
|------|--------|
| 颠覆认知 | 和直觉相反的是 |
| 很多人不知道 / 没人注意到 | 删掉 |
| 信号很明确 | 放在一起看，有一个共同的模式 |
| 下半场开始 / 新时代 | 这是一个值得注意的转向 |
| 改写规则 / 彻底改变 / 巨变 | 会带来具体的变化（然后列出来） |
| 革命 / 炸裂 / 史诗级 | 删掉 |
| 你还不知道就晚了 / 再不行动就 | 删掉（禁止制造焦虑） |
