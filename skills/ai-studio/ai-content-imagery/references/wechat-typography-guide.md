# 公众号排版设计说明（wechat-light 主题）

> 本主题专为微信公众号正文排版设计，解决公众号编辑器的兼容问题，同时保持专业的中文阅读体验。

## 设计原则

### 1. 兼容性优先
公众号编辑器的富文本解析能力有限，很多 HTML/CSS 特性会被过滤或变形。因此：
- 不用 `<table>` 原生表格，改用 flex div 布局
- 不用 CSS 类名依赖过深的选择器，尽量用内联样式+简单类名
- 不依赖伪元素 `::before/::after` 的复杂效果
- 链接一律保留（公众号会自动识别，但外链不可点击是平台限制）

### 2. 移动端阅读舒适
公众号 90%+ 阅读场景在手机上：
- 正文 16px，行高 2（手机屏行距不能太紧）
- 段落首行缩进 2em（中文排版规范，公众号读者习惯）
- 最大宽度 677px（公众号正文区域宽度）
- 留白充足，段落间距 16px

### 3. 视觉层级清晰
- **H2**：左侧 4px 微信绿竖条 + 字号 20px + 加粗，章节感强
- **H3**：字号 + 虚线底边分隔，次级标题不抢戏
- **加粗**：深灰色（#1a1a1a），不滥用颜色
- **强调文字**：微信绿或琥珀色，按语义选色

## 组件库

### 导读卡片（card-guide）
**用途**：文首摘要，让读者 5 秒知道文章讲什么
**语法**：
```markdown
> 💡 导读：本文拆解 XX 事件，从 A、B、C 三个角度分析，最后给出 D 建议。
```
**视觉**：左侧 4px 绿竖条 + 浅绿背景（#f0fdf4）

### 信息卡片（card-prize）
**用途**：突出关键数据、奖项、参数列表
**语法**：
```markdown
> 🏆 挑战赛基本信息：时间 10 天，奖金池 $35,000，10 个获奖名额
```
**视觉**：绿蓝渐变背景 + 边框，视觉重量最重，适合数据密集型内容

### 警示卡片（card-warning）
**用途**：风险提示、关键判断、需要读者注意的点
**语法**：
```markdown
> ⚠️ 关键判断：方向大概率正确，但现在的形态不一定是最终形态。
```
**视觉**：琥珀色（#f59e0b）+ 米黄背景，视觉上有"停下来注意"的感觉

### 质量说明卡片（card-quality）
**用途**：文末质量声明、信息来源说明
**语法**：
```markdown
> ✓ 质量说明：本文基于公开一手信息整理，所有事实性陈述均可追溯来源。
```
**视觉**：浅绿边框 + 浅绿背景，字号 13.5px，弱化但信息完整

## Emoji → 卡片类型映射

| Emoji | 卡片类型 | 典型场景 |
|-------|----------|----------|
| 💡 📌 🎯 | guide（导读） | 文首摘要、要点提示、核心结论 |
| 🏆 💎 | prize（信息） | 数据盘点、奖项参数、规格列表 |
| ⚠️ ⚠ | warning（警示） | 风险提示、关键判断、注意事项 |
| ✅ ✓ | quality（质量） | 质量声明、信息来源、可信度说明 |
| 其他 | default（默认） | 通用卡片，使用主题 accent 色 |

**语法规则**：
- 必须是引用块（`>` 开头）
- 第一行格式：`emoji + 空格 + 标题 + 中文/英文冒号 + 正文`
- 冒号用中文冒号「：」或英文冒号「:」都可以
- 标题和正文之间可以有空格，也可以没有

## Div 表格（公众号兼容）

### 为什么不用原生 table
公众号编辑器对 `<table>` 的支持很差，常见问题：
- 边框丢失
- 宽度错乱
- 内容溢出
- 复制粘贴后格式全乱

### Flex div 方案
用 `display: flex` 的 div 模拟表格，所有公众号编辑器都能正确渲染。

**列宽分配规则**（自动）：
- 2 列表格：1 : 2.5（第一列窄，第二列宽）
- 3 列表格：1 : 1 : 1.5（前两列等宽，第三列稍宽）
- 4+ 列表格：均分

**斑马纹**：偶数行浅灰背景（#fafafa），提升可读性。

### 使用方式
Markdown 里正常写表格，脚本自动转换。不需要改写作习惯。

```markdown
| 名称 | 角色 | 说明 |
|------|------|------|
| A | 角色1 | 说明1 |
| B | 角色2 | 说明2 |
```

## 使用方法

```bash
# 生成公众号版 HTML
python3 scripts/generate_article.py input.md output.html \
  --title "文章标题" --subtitle "副标题" --theme wechat-light
```

生成后用浏览器打开，全选复制，粘贴到公众号编辑器即可。大部分样式能保留，个别细节（如渐变背景）可能需要在编辑器里微调。

## 已知限制

1. **公众号外链不可点击**：平台限制，所有外部链接都会被剥离或变成纯文本。文末参考来源建议只放域名，不放完整链接。
2. **渐变背景可能丢失**：部分公众号编辑器不支持 `background: linear-gradient()`，信息卡片的渐变可能退化为纯色。不影响可读性。
3. **代码块字体**：公众号编辑器可能覆盖等宽字体设置。代码块建议用深色背景+浅色文字，对比度足够就好。
4. **首行缩进**：粘贴后如果首行缩进失效，检查编辑器是否自动清除了 `text-indent`。可以手动在编辑器里用空格替代。
