# AI 内容配图生成

> 本技能是 ai-studio 内容生产体系的视觉渲染层。内容质量规则见体系共享规则 `../shared/RULES.md`。
> 本技能只负责：把已有内容变成好看的 HTML/图片。 (AI Content Imagery)

## When to use
- 需要给 AI 内容做配图、封面图、长图
- 小红书封面/内页图、头条首图、公众号封面/长图
- 信息图、数据卡、对比图生成
- 批量生成多图内容包

## 技术方案
- **渲染**：HTML/CSS 模板 → Chromium headless 截图成 PNG
- **为什么不用 weasyprint**：用户否决，拒绝 PDF 中间格式
- **为什么不用 Playwright**：当前环境下直接用系统 Chromium 更轻量，零依赖
- **字体**：系统中文字体（思源黑体/PingFang/Noto Sans CJK/文泉驿正黑）
- **输出**：HTML 页面（默认） + PNG 长图（可选）

## 模板库

### 1. 大字封面模板（通用）
**适用**：所有内容类型的封面
**结构**：
- 背景层（纯色/渐变/轻纹理）
- 主标题（超大号字，1-2行）
- 副标题（中号字，补充说明）
- 标签组（内容类型/平台/日期等小标签）
- 底部装饰线或 logo

### 2. 清单/盘点模板
**适用**：工具盘点、N件事、周盘点
**结构**：
- 顶部标题区（大标题+副标题）
- N 个条目卡片（图标+标题+一句话描述）
- 网格布局（2列或3列）
- 底部总结或 call to action

### 3. 对比模板
**适用**：对比分析、实测对比、新旧对比
**结构**：
- 顶部标题
- 左右两列对比（或上下）
- 中间 VS 分隔
- 多行对比项，每一项左右各一个数据/描述
- 底部结论行

### 4. 教程步骤模板
**适用**：效率技巧、实操教程、方法步骤
**结构**：
- 顶部标题
- N 个步骤块（编号圆/数字 + 步骤标题 + 说明 + 截图占位）
- 垂直排列
- 底部总结或提示

### 5. 数据卡模板
**适用**：数据盘点、行业数据、关键指标
**结构**：
- 顶部标签（分类/来源）
- 中央大数字（最醒目的位置）
- 数字下方说明文字
- 趋势箭头/小图表
- 补充信息（时间/单位/来源）

### 6. 全文长图模板
**适用**：深度文全文长图、公众号转长图
**结构**：
- 标题区（大标题+作者+日期）
- 多段内容区（小标题+正文+引用块+列表）
- 图片占位区
- 结尾区（引导关注/二维码占位）
- 宽度固定 1080px，高度自适应

## 渲染实现

### 技术栈
- HTML5 + CSS3（Flexbox/Grid 布局）
- Chromium headless --screenshot（系统原生，无第三方 Python 依赖）
- Python 脚本驱动（标准库即可）

### 渲染脚本接口
```
输入：
  template: 模板名
  data: 内容数据（Markdown / JSON）
  theme: 主题名
  platform: 平台名（决定尺寸）
输出：
  HTML 文件路径（默认）
  PNG 文件路径（可选，--png 开启）
```

### 质量要求
- 默认 HTML 输出：可直接在浏览器打开，响应式布局
- PNG 截图：高清无锯齿，文字清晰
- 颜色准确（sRGB）
- 文件大小适中

## 配图素材来源与版权

### 可用来源
| 类型 | 来源 | 版权说明 |
|------|------|----------|
| 新闻配图 | 媒体原图 og:image | 评述性使用，带来源标注 |
| 软件截图 | 软件/网站界面 | 自有/公开软件，评述性使用 |
| 图标 | Heroicons / Font Awesome / Lucide | 免费商用 MIT/SIL |
| 图表 | 自制数据可视化 | 自有版权 |
| 渐变/纯色背景 | CSS 生成 | 自有 |

### 红线（绝对不碰）
- 明星肖像商用图
- 带其他平台水印的图
- 无来源的网图转载
- 版权不明的摄影作品
- 品牌 logo 商用（除非获授权）

### 核验策略
- 有明确来源的用来源可信度兜底
- 自制模板图 = 零版权风险（最推荐）
- 用户发布前目检最终效果
- 不假装"看过"图片内容（无视觉模型时诚实说明）

## 深度长文模板（已实现）

### 模板文件
- 生成脚本：`scripts/generate_article.py`
- 功能：Markdown → 精美 HTML 页面 → 可选 PNG 长图
- 技术：纯 Python（无第三方依赖）+ Chromium headless 截图

### 支持的主题

| 主题名 | 风格 | 适用场景 |
|--------|------|----------|
| `tech-dark` | 深蓝渐变+科技感 | AI/技术类深度长文（默认） |
| `light-minimal` | 白底+简约 | 通用/正式/周报 |
| `warm-dark` | 暖色暗夜+橙色点缀 | 工具/效率/创业类 |
| `toutiao-dark` | 深色+短段落+高对比 | 头条信息流文章 |
| `plain` | 朴素白底+无装饰 | 复制粘贴到各平台后台 |
| `wechat-light` | 白底+微信绿+卡片组件 | 微信公众号正文发布 |

### 支持的 Markdown 元素
- 标题（h1-h6）
- 段落 + 加粗 + 斜体 + 行内代码
- 无序列表 + 有序列表
- 表格（含表头分隔行）
- 引用块（blockquote）
- 代码块
- 水平分隔线

### 使用方法

```bash
# 生成 HTML（默认输出）
python3 scripts/generate_article.py input.md output.html \
  --title "文章标题" --subtitle "副标题" --theme tech-dark

# 公众号版（白底+微信绿+div表格+卡片组件）
python3 scripts/generate_article.py input.md output.html \
  --title "文章标题" --subtitle "副标题" --theme wechat-light

# 额外生成 PNG 长图（可选，需要系统 Chromium）
python3 scripts/generate_article.py input.md output.html \
  --title "文章标题" --theme tech-dark --png --png-width 760
```

### 交付习惯
- **默认发 HTML 原文件**，不打包 tar.gz
- PNG 长图为可选附加产物，不默认生成（用户需要才生成）
- 飞单发文件时注意：lark-cli 的 --file 参数要求相对路径，需要 cd 到文件所在目录再发

### 设计规格
- 内容宽度：760px（桌面端最佳阅读宽度）
- 基础字号：17px
- 行高：1.8
- 标题字号：h1=32px / h2=24px / h3=20px
- 边距：上下 60/80px，左右 40px
- 响应式：640px 以下自动适配移动端

### 环境依赖
- **系统 Chromium**：`apt install chromium`（用于 PNG 截图）
- **中文字体**：系统需有中文字体（文泉驿正黑 / Noto Sans CJK / PingFang SC / 微软雅黑）
- 只生成 HTML 不需要任何依赖，纯 Python 标准库

### Pitfalls（长文模板）
- **中文字体缺失**：Chromium 截图时如果没有中文字体会变成豆腐块。部署后先验证字体
- **只生成 HTML 不用 Chromium**：HTML 文件本身可以直接在浏览器打开，不截图就不需要 Chromium
- **长图大小**：文章越长 PNG 越大，几千字的长文可能 500KB-2MB，注意平台上传限制
- **不要用 weasyprint**：用户明确否决，坚决不走 PDF 中间格式。直接 HTML → Chromium 截图
- **公众号用 wechat-light 主题**：公众号编辑器对原生 table、CSS 渐变等支持差，`wechat-light` 主题自动用 div 表格+内联样式优先，复制粘贴后样式保留率最高。卡片组件语法参考 `references/wechat-typography-guide.md`


## Pitfalls
- **weasyprint 被用户否决**：坚决不用 PDF 中间格式，直接 HTML → Chromium 截图
- **中文字体**：必须确认系统有中文字体，否则渲染成豆腐块。部署时先验证字体
- **首屏 vs 全页**：封面图截首屏，长图截全页。别搞混
- **图片大小**：小红书/头条对图片大小有限制，超了会被压缩，注意控制
- **文字溢出**：模板必须考虑长文本情况，用 ellipsis 或自适应字号，不能文字溢出
- **lark-cli 发文件路径坑**：--file 参数要求相对路径，必须 cd 到文件所在目录再发
