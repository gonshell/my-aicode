# AI 内容数据复盘 (AI Content Metrics)

> 本技能是 ai-studio 内容生产体系的数据层。内容质量规则见体系共享规则 `../shared/RULES.md`。
> 本技能只负责：数据采集、指标分析、爆款归因、优化建议。

## When to use
- 每周/每月内容数据复盘
- 分析爆款内容为什么爆
- 优化选题方向和内容策略
- A/B 测试设计与结果分析
- 选题命中率追踪

## 核心原则
- **数据是结果，不是目标**——盯数据是为了找规律，不是为了 KPI
- **先找模式，再找原因**——先看"什么类型的数据好"，再分析"为什么好"
- **控制变量**——归因时尽量只变一个因素，否则说不清
- **小步快跑**——每次只调一个方向，看数据反馈再决定要不要放大

## 三平台数据采集

### 数据来源与采集方式
| 平台 | 数据来源 | 采集方式 | 频率 |
|------|----------|----------|------|
| 今日头条 | 创作者后台 | 手动导出 CSV 或截图记录 | 每日/周 |
| 小红书 | 创作者中心 | 手动记录数据 | 每日/周 |
| 公众号 | 公众号后台 | 手动导出 Excel | 每周 |

### 每篇内容必记字段
```
日期
平台
内容类型（工具盘点/实测/效率技巧/避坑/热点解读/深度/周盘点）
标题
发布时间
阅读/曝光量
完读率/点击率
互动数（点赞+评论+收藏+转发）
涨粉数
收益（如有）
备注（是否蹭了热点、有没有异常）
```

## 指标体系与健康阈值

### 五层指标模型

| 层级 | 指标 | 含义 | 头条健康线 | 小红书健康线 | 公众号健康线 |
|------|------|------|-----------|-------------|-------------|
| L1 流量 | 曝光量 / 阅读量 | 多少人看到了 | - | - | - |
| L2 转化 | 完读率 / 点击率 | 看到的人有多少愿意读 | >30% | >8% | 打开率>5% |
| L3 互动 | 互动率 | 读完的人有多少愿意动 | >2% | 收藏率>10% | 转发率>2% |
| L4 增长 | 涨粉率（粉/阅） | 多少人因为这篇关注你 | >0.5% | >1% | >1% |
| L5 收益 | 万次阅读收益 | 变现效率 | 10-50元 | 间接（广告） | 20-80元 |

### 关键判断
- **L2 不行** = 标题/封面/开头有问题 → 优化钩子
- **L3 不行** = 内容质量/选题共鸣有问题 → 优化内容本身
- **L4 不行** = 人设/价值感不清晰 → 优化结尾引导和账号定位
- **L5 不行** = 变现路径或品类选择有问题 → 调方向

## 爆款归因框架

### 爆款分析 5 问

每次遇到爆文（或扑街文），按这 5 个维度拆解：

**1. 选题维度**
- 属于什么内容类型？（工具/实测/教程/避坑/热点/深度/盘点）
- 属于什么赛道？（工具/职场/创业/技术/科普）
- 目标读者是谁？（程序员/产品/普通人/创业者）

**2. 标题维度**
- 用了哪种钩子公式？（数字/反常识/亲测/警示/对比/悬念）
- 标题长度？（多少字）
- 有没有关键词？（蹭了什么热点词）

**3. 开头维度**
- 前 3 行是什么钩子？（痛点/反常识/亲身经历/数字冲击）
- 开头有多久进入正题？

**4. 结构维度**
- 用了什么结构？（清单体/对比体/叙事体/层层递进/多方视角）
- 段落长度？节奏怎么样？
- 有没有金句/加粗/清单体等节奏变化？

**5. 时机维度**
- 发布时间点？（早/午/晚/深夜）
- 星期几？
- 有没有蹭上当天热点？
- 发布后前 30 分钟数据怎么样？（冷启动期表现）

### 归因方法
- **同类型对比**：同样是工具盘点，为什么这篇爆了那篇没爆？
- **控制变量法**：同一个选题，换了标题数据差多少？
- **累计模式**：10 篇爆文放在一起看，有什么共同点？

## 复盘节奏

### 日度：快速扫
- 每篇看一眼：阅读量、完读率、互动率
- 标记异常值：爆了（超预期 2 倍以上）或扑了（低于预期一半）
- 花 5 分钟记一下：大概为什么？

### 周度：完整复盘（重点）
**输出物：周复盘报告**

结构：
```
1. 本周数据总览
   - 总阅读/总互动/总涨粉/总收益
   - 各平台分别数据
   - 环比上周变化

2. 内容表现排行
   - Top 3 爆款（每篇简单归因）
   - Bottom 3 扑街（每篇分析原因）
   - 按类型统计平均表现

3. 选题命中率分析
   - 各内容类型的平均阅读/互动/涨粉
   - 命中率最高的 2-3 个类型
   - 数据最差的类型（要不要砍？）

4. 标题/开头/结构分析
   - 爆款标题用了哪些钩子？
   - 扑街文的开头有什么共同点？
   - 哪种结构的数据最好？

5. 下周优化建议
   - 继续放大什么
   - 停止做什么
   - 测试什么新方向
```

### 月度：大盘判断
- 整体趋势（增长/持平/下滑）
- 内容类型命中率排行榜更新
- 平台侧重调整（哪个平台涨得好就加码）
- 下月目标与策略

## 选题命中率追踪系统

### 选题表现表
| 内容类型 | 篇数 | 平均阅读 | 平均互动率 | 平均涨粉率 | 爆款率 | 综合评分 |
|----------|------|----------|-----------|-----------|--------|----------|
| 工具盘点 | - | - | - | - | - | - |
| 实测体验 | - | - | - | - | - | - |
| 效率技巧 | - | - | - | - | - | - |
| 避坑指南 | - | - | - | - | - | - |
| 热点解读 | - | - | - | - | - | - |
| 深度长文 | - | - | - | - | - | - |
| 周盘点 | - | - | - | - | - | - |

### 评分逻辑
- 综合评分 = 完读率×0.3 + 互动率×0.3 + 涨粉率×0.3 + 爆款率×0.1
- 权重可根据阶段目标调整（涨粉期涨粉率权重高，收益期收益权重高）

### 决策原则
- **前 2-3 名类型**：加码，增加频率，深入做
- **中间类型**：维持，作为内容多样性补充
- **后 2 名类型**：连续 2 周垫底 → 砍掉或大幅改版

## A/B 测试方法

### 测试什么（优先级从高到低）
1. **标题**（影响最大，改起来最便宜）
2. **封面**（小红书特别重要）
3. **发布时间**
4. **开头写法**
5. **内容结构**

### 怎么测
- **同内容不同标题**：同一个内容写两个不同标题，在同一平台不同时间发，或在不同平台发
- **同类型不同时间**：同一类型内容，分别在早/中/晚发，看哪个时段数据好
- **同素材不同结构**：同一个素材用两种结构写，对比效果

### 判断标准
- 数据差 30% 以上 = 有显著差异
- 数据差 10-30% = 有倾向，再测一次确认
- 数据差 10% 以内 = 没区别，怎么都行

### 注意事项
- 一次只测一个变量——同时改标题和结构，说不清是哪个的作用
- 样本量不能太少——阅读量低于 1000 的话，数据波动太大，不作数
- 测试结论要结合定性判断——数据只是辅助，别迷信

## 常见误区

1. **只看阅读量，不看完读率**
   阅读量高可能只是标题党，完读率才代表内容真的吸引人。低完读率的高阅读=饮鸩止渴。

2. **只看单篇，不看趋势**
   单篇爆了可能是运气。连续 5 篇同类型数据都好，才是真的找对了方向。

3. **数据不好就全否定**
   一篇扑街不能说明这个类型不行。至少 5 篇同类型数据都不好，再下结论。

4. **过度优化，越做越累**
   数据是指南针，不是紧箍咒。大概方向对就行，别追求每篇都最优。稳定更新比偶尔精品重要。

5. **照搬别人的经验**
   别人的爆款公式是别人的，你的账号有你的受众和调性。参考可以，照搬必扑。

## 与主技能的关系
- 本技能被 `ai-content-production` 定期调用（周/月复盘）
- 主技能负责生产内容，本技能负责评估和优化内容
- 输入：内容数据 + 文章清单 → 输出：复盘报告 + 优化建议

## Pitfalls
- **初期数据少别瞎分析**：不到 20 篇内容、不到 1 个月数据，不足以得出可靠结论。先积累数据，再谈优化。
- **相关性 ≠ 因果**：爆款同时用了 A 标题和 B 结构，不能确定就是 A 的作用。要验证得做控制变量。
- **数据焦虑**：别每天盯着数据刷新，没意义。固定节奏复盘（日扫+周复盘），其他时间专心做内容。
- **别为了数据丢了质量**：为了完读率把内容写得越来越水，短期数据好看，长期伤账号。
