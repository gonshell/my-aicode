# 技术博客六类骨架详细模板

> 每种骨架给出：适用场景、核心逻辑、标准结构、检验方法、示例标题。
> 这些是结构参考，不是铁律。根据素材形状灵活调整。

---

## 1. 拆解型（默认骨架）

**适用场景**：新技术发布、新概念解析、新产品深度解读
**核心逻辑**：是什么 → 怎么工作 → 为什么重要 → 现状与局限 → 未来影响
**要回答的问题**："这东西到底是什么？怎么工作的？意味着什么？"

### 标准结构

```
【标题】XX：一句话定义 + 一个好懂的类比

开头（钩子）
  用一个场景/一个问题/一个数据抓住读者
  一句话说出核心判断

一、是什么（建立共识）
   一句话精确定义
   最通俗的类比 + 类比边界
   和容易混淆的概念划清边界（和XX的区别）
   谁做的、什么时候出来的、处于什么阶段

二、怎么工作（技术原理）
   核心架构/工作流程（分层讲）
   关键技术点拆解（2-4个最重要的）
   技术细节 + 类比解释并行
   配合架构图/流程图/表格辅助理解

三、为什么重要（价值判断）
   解决了什么真问题？
   之前的方案有什么痛？
   这个东西的独特价值在哪？
   和现有方案的对比（关键维度对比表）

四、现状与局限（反方视角）
   现在处于什么阶段？（研究预览/正式版/成熟）
   有什么坑？技术上的、工程上的、生态上的
   什么情况下不适用？
   已知的质疑和批评

五、未来与影响（升维判断）
   短期会怎样？（6-12个月）
   长期可能改变什么？
   对不同角色的意义（开发者/产品/管理者/普通人）
   放在更大的行业图景里看

结尾（留钩子）
  一句话总结核心判断
  一个值得思考的问题/一个画面
```

### 检验方法
- 读者从零开始读，能准确回答"这是什么、怎么工作、为什么重要"吗？
- 技术部分有没有准确性问题？
- 反方视角是不是真的有质量，还是只是应付？

### 示例标题
- "MHS：Anthropic把AI伸进物理世界的'USB接口'"
- "Mamba：Transformer之后的下一代序列模型？"

## 2. 对比型

**适用场景**：技术选型、方案对比、竞品分析、新旧技术对比
**核心逻辑**：A是什么 → B是什么 → 多维度对比 → 选型建议
**要回答的问题**："A和B哪个好？怎么选？"

### 标准结构

```
【标题】XX vs YY：差距比想象的大/怎么选才对

开头
  说明为什么要对比（大家都在问/选型很纠结/两者经常被放在一起比）
  一句话给出你的结论倾向（别藏到最后）

一、A 是什么
   基本情况：谁做的、什么时候、定位
   核心特点：3-5个关键特性
   优势在哪
   劣势在哪

二、B 是什么
   同上，结构对称

三、核心维度对比
   用表格对比 5-8 个关键维度
   （性能/成本/易用性/生态/成熟度/适用场景…）
   每个维度下面展开说：为什么会有这个差异？背后的原因是什么？

四、不同场景下怎么选
   场景1：选A，为什么
   场景2：选B，为什么
   场景3：都不选，还有别的方案
   （这一部分是对比文的价值所在，不是列个表就完了）

五、我的判断
   综合来看，谁更有前景？为什么？
   哪些情况下两者其实不构成竞争？
   未来可能的走向

结尾
  一句话选型建议
  留一个互动问题
```

### 检验方法
- 对比维度是不是真的重要，还是凑数？
- 每个维度的差异有没有解释原因（不只是列数据）
- 选型建议是不是具体、可操作？

### 示例标题
- "PPO vs DPO vs GRPO：大模型对齐算法到底怎么选？"
- "GPT-4o vs Claude Opus 5：实测对比，差距在哪？"

## 3. 教程型

**适用场景**：实操指南、踩坑记录、工具使用教程、环境搭建
**核心逻辑**：问题/目标 → 方案 → 步骤 → 效果 → 注意事项
**要回答的问题**："怎么做到？有什么坑？"

### 标准结构

```
【标题】手把手教你XX：从零开始到跑通

开头
  说清楚这篇教程要解决什么问题
  读完能达到什么效果
  前置条件（需要什么基础/环境）

一、准备工作
   环境要求
   依赖安装
   账号/密钥等准备

二、核心步骤
   步骤1：XXX
     做什么 + 为什么这么做 + 代码/命令 + 预期结果
   步骤2：XXX
     同上
   ...
   （3-8个步骤，每个步骤完整可复现）

三、验证效果
   怎么确认成功了？
   预期输出是什么样？
   简单测试用例

四、常见坑与解决方案
   坑1：XXX → 原因 → 解决
   坑2：XXX → 原因 → 解决
   ...

五、进阶玩法（可选）
   还能怎么扩展？
   有什么高级用法？

结尾
  总结关键步骤
  鼓励动手 + 互动
```

### 检验方法
- 每个步骤是不是可以照做？命令/代码是不是完整？
- 坑是不是真的常见，还是编的？
- 读者从零开始能不能跟着跑通？

### 示例标题
- "从零搭建 MCP 服务器：手把手教程"
- "QLoRA微调Llama 3 7B：踩坑全记录"

## 4. 盘点型

**适用场景**：一类技术/工具/框架全景、行业格局、年度盘点
**核心逻辑**：背景 → 逐个盘点 → 横向对比 → 趋势判断
**要回答的问题**："现在有哪些玩家？格局怎样？趋势是什么？"

### 标准结构

```
【标题】XX领域N大玩家：第X个最值得关注

开头
  这个领域为什么值得关注？
  当前处于什么阶段？
  本文盘点范围说明

一、玩家1：XXX
   基本情况（谁做的、定位、融资/体量）
   核心特点
   优势与劣势
   最新动态

二、玩家2：XXX
   同上

...（N个，3-10个为宜）

N+1、横向对比
   用一张表对比所有玩家的关键维度
   不同维度的排名

N+2、趋势判断
   这个领域的几个核心趋势
   哪些方向值得关注？
   未来6-12个月可能发生什么？

结尾
  一句话总结格局
  给不同读者的建议（开发者/创业者/投资者）
```

### 检验方法
- 盘点是不是全面？有没有漏掉重要玩家？
- 每个玩家的描述是不是信息量对等？（不能有的详细有的一笔带过）
- 趋势判断是不是有依据，还是拍脑袋？

### 示例标题
- "2026年最值得关注的5个AI Agent框架"
- "大模型推理芯片全景：10家玩家深度盘点"

## 5. 深潜型

**适用场景**：技术原理深度拆解、底层机制解析、数学原理
**核心逻辑**：表面现象 → 第一层原理 → 第二层 → 本质 → 延伸意义
**要回答的问题**："底层原理到底是什么？为什么是这样？"

### 标准结构

```
【标题】XX底层原理拆解：从入门到本质

开头
  为什么要深潜这个技术？
  表面上它是什么，但底层其实很不一样
  本文会挖到哪一层

一、基础层：表面上怎么工作
   最直观的理解
   入门级解释
   （让初学者也能跟上）

二、中间层：核心机制
   真正的工作原理
   关键技术点拆解（2-3个）
   配合公式/伪代码/示意图
   （这是文章的主体，专业读者最关心的部分）

三、深层：为什么是这样
   为什么这么设计？不这么做会怎样？
   设计取舍（trade-off）
   历史演进：从之前的方案到现在，为什么走到了这一步

四、本质层：最底层的逻辑
   这个技术最核心的洞察是什么？
   一句话说透本质
   它解决的根本矛盾是什么？

五、延伸：从本质看未来
   理解了本质，能推导出什么？
   这个技术的极限在哪？
   下一代可能是什么样？

结尾
  一句话总结本质
  一个思考题
```

### 检验方法
- 是不是真的一层比一层深？（不是平行的几个点）
- 每一层之间的逻辑衔接是不是顺？
- "本质"那一层是不是真的有洞见，还是换个说法重复？

### 示例标题
- "注意力机制的数学本质：为什么Transformer这么强？"
- "深度拆解MoE：混合专家到底是怎么工作的？"

## 6. 观点型

**适用场景**：趋势判断、争议话题、行业观察、反常识观点
**核心逻辑**：亮明观点 → 论据1/2/3 → 反方 → 让步 → 结论
**要回答的问题**："我认为XX，为什么？"

### 标准结构

```
【标题】我的判断：XX正在发生/XX是个伪命题

开头
  直接亮明观点（别藏）
  说明这个观点为什么重要/有争议
  预告论证结构

一、论据1：XXX
   事实/数据/案例
   为什么这能支撑我的观点

二、论据2：XXX
   同上

三、论据3：XXX
   同上

（3个论据最佳，2个太弱，4个太多）

四、反方怎么说
   最有力的反对意见是什么？
   （要诚实，不要树立稻草人）
   这个意见有没有道理？

五、我的回应与让步
   哪些地方我承认对方说得对？（让步）
   哪些地方我不同意？为什么？
   我的观点的边界和适用条件是什么？

六、结论
   综合之后，我的最终判断
   这个判断意味着什么？

结尾
  一句话重申核心观点
  一个留钩子的问题
```

### 检验方法
- 观点是不是明确？（不是"一方面/另一方面"的废话）
- 论据是不是站得住？（有事实/数据/案例支撑）
- 反方是不是真的有质量？（不是稻草人）
- 让步是不是真的？（不是"虽然有人反对但他们错了"这种假让步）

### 示例标题
- "为什么我认为AI Agent的爆发还需要两年"
- "MHS成不了硬件界的USB，三个原因"
