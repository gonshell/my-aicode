## 核心设计（速览）

- **双轨制**：先生产端（知识工程工厂）后消费端（知识服务）
- **5条硬约束**：结构化输入 / 可解释性 / 负面知识同等重要 / 专家减负先行 / 决策权在人
- **四维知识结构**：现象 → 判断 → 行动 → 边界
- **独立负面知识库**：错误教训与正面知识同等权重
- **自动衰减机制**：知识半衰期，过期自动降级
- **ROI 先行**：全年投入约172万，收益测算模型已建
