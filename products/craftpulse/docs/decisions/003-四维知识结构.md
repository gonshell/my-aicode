# ADR-003：四维知识结构（现象→判断→行动→边界）

- **状态**：已接受（2026-08-01）
- **影响范围**：知识表示层、编辑器设计、质检规则

## 背景

专家知识需要被机器解析和检索，传统线性文档无法承载。需要确定知识的原子化表示模型。

## 候选方案

1. **三段式**（是什么/怎么做/注意什么）——传统方案，边界模糊
2. **四维结构**（现象层/判断层/行动层/边界层）
3. **纯自由文本 + LLM语义解析**——不结构化

## 权衡

| 方案 | 优点 | 缺点 |
|:---|:---|:---|
| 三段式 | 简单 | 判断逻辑与现象描述混在一起；边界（不适用场景）无位置存放 |
| 四维结构 | 完整覆盖专家决策链；可测试；可溯源 | 填写成本高，需约束支撑 |
| 自由文本 | 专家负担小 | 质量不可控；无法做回归测试 |

## 决定

采用**四维知识结构**：

1. **现象层**：什么症状、什么参数异常（回答"看到了什么"）
2. **判断层**：怎么判断原因、决策逻辑（回答"怎么想"）
3. **行动层**：怎么处理、步骤顺序、安全红线（回答"怎么做"）
4. **边界层**：适用条件、不适用条件、反例（回答"什么时候不灵"）

## 理由

1. 四维对应专家真实的决策链：观察→判断→行动→纠偏，符合认知过程
2. 边界层是专家经验最值钱的部分（"这套方法什么时候不适用"），传统模型没有位置放它
3. 每层都有独立校验规则，可测试、可质检、可衰减——支撑后续所有质量机制

## 后果

- 编辑器按四栏布局设计（原型 v0.5 已验证）
- 质检机器人12项规则基于四维结构设计
- 负面知识（错误教训）用独立结构存放（见 ADR-004），不与四维正面知识混用
