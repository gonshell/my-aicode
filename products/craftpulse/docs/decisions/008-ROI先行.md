# ADR-008：ROI 先行与全年投入测算

- **状态**：已接受（2026-08-01）
- **影响范围**：项目立项、预算决策、推进节奏

## 背景

知识管理项目在组织内最难回答的问题是："投这么多钱，到底能赚回什么？"没有 ROI 测算，项目无法立项、无法持续获得资源，也容易在中期被叫停。

## 候选方案

1. **先做后算**：项目做完再评估效果
2. **ROI 先行**：立项阶段就建立投入/收益测算模型，作为项目持续运营的依据
3. 只谈战略意义，不谈钱：知识管理是长期投入

## 权衡

| 方案 | 优点 | 缺点 |
|:---|:---|:---|
| 先做后算 | 简单 | 无法立项；中期被叫停风险高 |
| ROI先行 | 可立项、可续命；倒逼目标量化 | 测算有不确定性，需标注假设 |
| 只谈战略 | 高尚 | 无法说服决策层批预算 |

## 决定

采用**ROI 先行**，并完成首年测算（方案第33章）：

- **投入**：团队人力（CKO+知识工程师2+萃取师4+联络员）+ 工具 + 专家时间，全年约 172 万元
- **收益**：减少专家重复解答（年省 45-90万）、减少停机时间（年省 30-60万）、降低事故损失（年省 40-80万）等
- **核心ROI指标**：知识复用率、专家答疑时间节省、事故率下降
- 测算模型全程标注假设，随项目推进按实际数据修正

## 理由

1. 没有 ROI 数字，项目在决策层会议上无法存活——这是工业界的现实
2. 测算过程本身就是目标对齐：逼团队明确"什么指标证明项目有效"
3. 分阶段投入（试点→MVP→规模化），每阶段用阶段ROI说话，降低立项风险

## 后果

- 方案第33章成为立项材料核心部分
- 运营总控台需实时展示 ROI 相关指标
- 假设清单需要随试点数据持续修正（第9篇路线图）
